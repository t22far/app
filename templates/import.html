Import from QuickBooks

Export your data from QuickBooks Online UK, then upload the files below. Existing records are updated in place; manual adjustments are always preserved.

How to export from QuickBooks UK

  1. Employees CSV — first-time setup or when your team changes
    Payroll → Employees → export icon (top-right) → Export to CSV
  2. Leave Requests XLSX — upload this each time you want to sync leave
    Payroll → Time Off → Leave Requests → set date range to your leave year → Export
    The app reads Approved (taken) and Pending/Scheduled (upcoming) rows automatically.
  3. Time Off Summary CSV — optional, imports accrued allowances
    Payroll → Reports → Time Off Summary → set date range → Export

Columns: First name, Surname, Email address, Employment status, Job title, Department

Columns: Employee Id, Employee First Name, Employee Surname, Leave Category, Start Date, End Date, Units, Unit Type, Status

Columns: Employee, Policy, Accrued (hours), Used (hours), Scheduled (hours)
